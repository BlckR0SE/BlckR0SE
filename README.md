## About

Practicing minimalist, test-driven systems engineering. The core ethos: shortest diff wins, deletion over addition, root-cause resolution in shared primitives, zero unasked abstractions, and standard library tools before introducing external dependencies.

---

## What ships

- **[playBook](https://github.com/BlckR0SE/playBook)**: Repository of agentic skills, executable playbooks, and standardized developer workflows.
- **[DaalERP](https://github.com/BlckR0SE/DaalERP)**: Enterprise ERP suite built with Next.js, TypeScript, and modern relational storage.
- **[cloud-rdp](https://github.com/BlckR0SE/cloud-rdp)**: On-demand automated cloud virtual desktop and runner workflow via GitHub Actions.
